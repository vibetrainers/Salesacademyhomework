# Домашние задания

Сайт для сдачи домашних заданий по 6 урокам.

- **Вход** по индивидуальному коду, без регистрации. Коды создаёт администратор, в системе хранятся только коды, без ФИО.
- **Сдача:** участник выбирает филиал и продукт, отвечает текстом. В уроке 1 — только текст, в уроках 2–6 можно приложить файл (фото уменьшаются прямо на телефоне).
- **Правка до срока:** до срока ответ можно изменить или удалить.
- **База ответов:** все видят ответы всех — филиал, продукты и сам ответ, без кода автора. Есть фильтры по продукту, уроку и филиалу и поиск.
- **Админка:** коды участников (создать, отключить, скачать списком), таблица сдачи, сроки, списки филиалов и продуктов, выгрузка ответов в Excel.

Сайт — статические файлы в `docs/` (GitHub Pages). Данные и файлы хранятся в Supabase, бесплатный тариф.

## Настройка (один раз)

1. Зарегистрируйтесь на https://supabase.com, создайте проект (**New project**), регион — **Central EU (Frankfurt)**.
2. Откройте **SQL Editor** и по очереди выполните три файла:
   - `supabase/schema.sql` — таблицы и функции;
   - `supabase/storage.sql` — хранилище для файлов;
   - `supabase/admin-password.sql` — пароль администратора (сначала замените `ВАШ_ПАРОЛЬ` на свой).
3. В **Project Settings → API** скопируйте **Project URL** и ключ **anon / publishable** и вставьте их в `docs/config.js`. Ключ публичный по задумке: доступ к данным ограничен функциями базы.
4. Выполните `npm run stamp` (номер версии на файлах — чтобы телефоны не показывали старую копию) и загрузите изменения на GitHub. Сайт обновится через минуту.
5. Зайдите на сайт → «Вход для администратора»:
   - на вкладке «Сроки и списки» заполните филиалы и сроки;
   - на вкладке «Коды участников» создайте коды и скачайте их списком.

## Важно

- **Пауза проекта.** Supabase на бесплатном тарифе приостанавливает проект, если неделю к нему никто не обращался. Чтобы этого не было, GitHub раз в 3 дня сам обращается к базе (`.github/workflows/keepalive.yml`). Если проект всё же встал на паузу, зайдите в панель Supabase и нажмите **Restore project**. Данные не пропадают.
- **Сброс проверки GitHub.** GitHub отключает такие автоматические проверки, если в репозитории 60 дней не было изменений. Тогда во вкладке **Actions** нажмите **Enable workflow**.
- **Лимиты.** Бесплатно доступно 500 МБ базы и 1 ГБ файлов. Фото сжимаются примерно до 300 КБ, документы — до 10 МБ. На 100 участников этого хватает с запасом.
- **Ответственность за коды.** Код — единственный ключ участника. Если код ушёл не тому человеку, отключите его в админке и выдайте новый.

## Локальная проверка

Нужны Node.js и PostgreSQL.

```bash
createdb domashki_dev
psql -d domashki_dev -f supabase/schema.sql
npm install
npm run dev
```

Откройте http://localhost:8790. Пароль администратора задаётся так же, как в `supabase/admin-password.sql`. Проверка логики базы: `psql -d domashki_dev -f dev/test.sql`.
